## 🌟 Overview

**Folioblox** is an interactive, design-first digital portfolio engineered to deliver an immersive narrative experience. Combining high-end editorial aesthetics with cinematic scroll-driven canvas animations, the platform reflects a blend of **brand strategy, industrial packaging design, and modern digital interfaces**.

> *"Great design should feel invisible. From logo to language, I build brands that connect and convert."*

---

## ✨ Key Features & Highlights

- **🎞️ Canvas Scroll-Scrub Animation**:
  - 240-frame synchronized background image sequence driven by user scroll depth.
  - Zero-flicker outward nearest-frame fallback algorithm with smooth retina DPR scaling.
- **💎 Dark Glassmorphic Aesthetics**:
  - Curated dark palette (`#050505` deep background, translucent frosted glass cards, subtle neon blue and soft orange accents).
  - Modern typography pairing: *Plus Jakarta Sans* for clean UI readability and *Playfair Display* for editorial elegance.
- **🧭 Two-Week Design Sprint Workflow**:
  - Interactive cascading timeline visualizing a structured 14-day design sprint (Research → Positioning → Landing Page → Visual Direction → AI Exploration → UI Execution).
- **🎨 Interactive Color Specification Stage**:
  - Segmented circular SVG ring with floating inspectable color cards detailing HEX, RGB, and opacity values.
- **📂 Multi-Page Experience**:
  - **`index.html`**: Hero scroll-track, brand partnerships, design philosophy, studio showcase, workflow, stats, and questionnaire form.
  - **`projects.html`**: Curated 2-column portfolio catalog with categorized tag filters covering hardware, fashion, packaging, digital UI/UX, and motion design.
- **📋 Lead Generation & Questionnaire**:
  - Interactive multi-step form tailored for client onboarding, business stage qualification, and project scoping.
- **⚡ Zero Bloat & 100% Vanilla Performance**:
  - No heavy frameworks, zero runtime overhead, instant page loads, and native responsiveness across mobile, tablet, and ultra-wide displays.

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser (Google Chrome, Firefox, Safari, Microsoft Edge). No Node.js or compiler required!

### 1. Clone the repository

```bash
git clone https://github.com/pabitralenka07/Portfolio_website.git
cd Portfolio_website
```

### 2. Run locally

You can launch the project using any local HTTP server:

**Using VS Code Live Server extension:**
- Right-click `index.html` and click **"Open with Live Server"**.

**Using Python:**
```bash
# Python 3.x
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

**Using Node.js (`npx serve`):**
```bash
npx serve .
```

## 🌐 Deployment

### GitHub Pages

1. Navigate to repository **Settings** on GitHub.
2. Select **Pages** from the left navigation menu.
3. Under **Branch**, select `main` and set folder to `/(root)`.
4. Click **Save**. Within a few minutes, your portfolio will be live at:
   ```
   https://pabitralenka07.github.io/Portfolio_website/
   ```
